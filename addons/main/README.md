# FCash Main Addon

This directory contains the runtime implementation of Fuhrizen's Cash.

- `config.cpp` - addon configuration, functions, remote execution, and UI registration.
- `cfg3den.hpp` - 3DEN object attributes and editor modules.
- `zeus.hpp` - Zeus module definitions.
- `functions/` - client, server, UI, persistence, 3DEN, and Zeus SQF functions.
- `ui/` - shared control styles and dialog definitions.
- `XEH_preInit.sqf` - CBA settings registration.

The PBO prefix is:

```text
x\fcash\addons\main
```
